## Uso recomendado
1. Leer primero la vision compartida.
2. Enviar el brief de backend a Jules.
3. Enviar el brief de frontend a Codex.
4. Mantener los slices propuestos; no mezclar backend y frontend en el mismo sprint.
5. Usar el tenant demo educativo para QA.

## Criterio del paquete
- Separar ownership.
- Bajar el riesgo de romper todo.
- Reposicionar chatboc.ar para colegios publicos y privados.
- Convertir WhatsApp en canal de entrada, no en limite del producto.
