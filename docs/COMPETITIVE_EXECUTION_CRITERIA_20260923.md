# Criterios verificables para competir — 23/09/2026

Estas referencias públicas orientan el backlog; no certifican paridad ni superioridad de ChatBoc. Se distinguen las capacidades documentadas por cada proveedor de nuestras decisiones de implementación.

| Referencia oficial revisada | Capacidad documentada | Criterio propuesto para ChatBoc |
|---|---|---|
| Jelou, Monitoreo / Human Connect | Filtros por equipo/canal/estado, reasignación y contexto de atención centralizado | Del indicador al caso y de allí a una acción autorizada, sin perder organización ni historial |
| respond.io, Reports: Responses / Conversations | Definiciones explícitas de métricas, períodos y bases de conversaciones | Cada métrica debe informar población, filtros, unidad y fecha; distribución no equivale a conversión |
| Manychat, Inbox | Asignación, notas, recordatorios y cierre/reapertura | Responsable, próxima acción y vencimiento persistentes; no simularlos con texto o sólo estado local |
| Humand, Insights / reportes de servicios | Adopción, actividad y reportes de solicitudes segmentables | Separar adopción de uso, volumen operativo y calidad del servicio |
| ChatBot.com, atención multicanal | Oferta de bandeja integrada y atribución de resultados | Verificar conexión, envío, recepción y resultado por canal antes de publicitarlo como operativo |
